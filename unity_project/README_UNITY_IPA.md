# Unity IPA project

This is the Unity 6.3 LTS client starter. The game connects to the dedicated IPA server configured in `Assets/Resources/GameServerConfig.asset` after Unity creates it.

See the project overview at [`../README.md`](../README.md) and the online contract at [`docs/UNITY_ONLINE_CONTRACT.md`](docs/UNITY_ONLINE_CONTRACT.md).

The Windows development machine does not currently have Unity Hub/Editor or Xcode, so no Unity build or IPA has been produced yet. Xcode on macOS is required for an iOS build/signing stage.
